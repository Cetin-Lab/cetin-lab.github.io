Research Software and Code

Selected software implementations developed in connection with research conducted by the Cetin Lab are available through the laboratory’s GitHub repositories. Project-specific documentation and implementation details are provided with each repository.

Python

Next-Day Wildfire Spread Prediction

Implementations of U-Net-based wildfire spread prediction models incorporating Hadamard and discrete cosine transforms, spectral fusion, and directional shearlet representations. Supporting materials include data preparation, model training, and evaluation utilities.

Repository
Cetin-Lab / Nextday-Wildfire-Spread-Prediction
Python

Satellite-Based Environmental Monitoring

Methods for wildfire and wind-erosion monitoring using satellite imagery and video. The implementations incorporate transform-based models and tiled processing for computationally efficient inference.

Repository
Cetin-Lab / Satellite_Wildfire_Monitoring
Python / Jupyter

Instantaneous Phase Estimation for Gearbox Signals

Dual-branch and joint neural network architectures incorporating Walsh–Hadamard layers for instantaneous phase estimation from gearbox vibration measurements.

Repository
Cetin-Lab / -Real-time_-Gearbox_Phase
Python

DEDUCT: DNA Sequence Compression

A DNA sequence-compression framework combining clustering, alignment, learned coding, and cosine-transform layers. The repository provides configuration files, public-data accessions, and verification utilities.

Repository
Cetin-Lab / deduct
